# 📦 eMRO Inventory Search — DM01 (Thai Lion Air)

ระบบค้นหาอะไหล่และติดตามความเคลื่อนไหวคลังสินค้า (`Inventory Transaction`) จากระบบ eMRO โดยไม่ต้องล็อกอินเข้า eMRO ทุกครั้ง

---

## ✨ คุณสมบัติหลัก

1. **ดึงข้อมูลครบทุกหน้าพร้อม Description 100%**
   - **วิธีหลัก (Primary):** สั่งกดปุ่ม Export Excel จากหน้า `Inventory Transaction` (Location = `DM01`) ซึ่งได้ข้อมูลครบทั้ง 1,246+ แถว พร้อมคอลัมน์ `DESCRIPTION`, `UOM`, `CONDITION`, `MAIN P/N` ในไฟล์เดียว (ใช้เวลา ~5–10 วินาที) แล้วนำเข้าฐานข้อมูล SQLite และลบไฟล์เก่าอัตโนมัติ (เก็บไว้เฉพาะ 3 ไฟล์ล่าสุด)
   - **วิธีสำรอง (Fallback):** หากปุ่ม Export ขัดข้อง ระบบจะสลับไปตั้งค่าแสดงผล 50 แถว/หน้า และไล่อ่านตารางทีละหน้าจนครบอัตโนมัติ
2. **ติดตามอะไหล่ที่ของหมด (Out-of-Stock Tracking)**
   - แก้ปัญหา eMRO ที่ซ่อนรายการเมื่อของหมด (`Avbl = 0`): ระบบจะคงรายการที่เคยมีไว้ในฐานข้อมูล พร้อมแสดงป้าย **`🔴 หมด (0)`**, **Bin ล่าสุดที่เคยอยู่**, และ **วันที่ของหมด (`หมดตั้งแต่...`)**
   - **ระบบป้องกันข้อมูลผิดพลาด (Safety Guard):** จะตั้งสถานะ "หมด" ก็ต่อเมื่อรอบนั้นดึงข้อมูลครบตามจำนวนหน้าที่ eMRO แจ้ง และจำนวนแถวไม่ลดลงผิดปกติเกิน 20%
3. **เก็บประวัติความเคลื่อนไหว (Stock Movement History)**
   - บันทึกทุกครั้งที่จำนวน `Avbl` เปลี่ยนแปลง (เช่น `11 → 9`) พร้อมแท็บ **"ของเข้า-ออกวันนี้"** และปุ่มกดดูประวัติราย P/N
4. **อัปเดตอัตโนมัติ + กด Refresh ได้ทันที**
   - ซิงก์ข้อมูลอัตโนมัติทุก **30 นาที** ในช่วงเวลาทำงาน **06:00–22:00 น. (ทุกวัน)**
   - ปุ่ม **"Refresh ตอนนี้"** บนหน้าเว็บ (ป้องกันด้วยรหัส PIN เริ่มต้น `123456`)

---

## 🚀 วิธีเปิดใช้งาน

- **เปิดใช้งานปกติ (LAN / เครื่องตัวเอง):** ดับเบิลคลิก `start_inventory.bat`
- **เปิดใช้งานพร้อมลิงก์ออนไลน์ (Cloudflare Tunnel):** ดับเบิลคลิก `start_inventory_online.bat`
- **URL เข้าใช้งาน:**
  - เครื่องตัวเอง: `http://localhost:8001`
  - เครื่องอื่นในวง LAN/Wi-Fi: `http://172.21.1.111:8001`

---

## ⚙️ การตั้งค่าใน `.env`

| ตัวแปร | ค่าเริ่มต้น | คำอธิบาย |
|---|---|---|
| `INVENTORY_USER` | `TL248005` | บัญชี eMRO สำหรับดึงข้อมูล (อ่านอย่างเดียว) |
| `INVENTORY_LOCATIONS` | `DM01` | รหัสคลังที่ต้องการดึง (คั่นด้วย `,` ได้ เช่น `DM01,BKK01`) |
| `SYNC_INTERVAL_MINUTES` | `30` | ความถี่ในการดึงข้อมูลอัตโนมัติ (นาที) |
| `SYNC_START_HOUR` / `SYNC_END_HOUR` | `6` / `22` | ช่วงเวลาทำงานของระบบดึงอัตโนมัติ (06:00–22:00) |
| `REFRESH_PIN` | `123456` | รหัส PIN สำหรับกดปุ่ม Refresh ตอนนี้ |
| `WEB_PORT` | `8001` | พอร์ตของเว็บเซิร์ฟเวอร์ (แยกจากระบบเปิดใบงานพอร์ต 8000) |
